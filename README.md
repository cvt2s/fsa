## Usage

Paste the script for your game into your executor and run it. Each script has its own README inside its folder with game-specific notes, known issues, and feature breakdowns.

---

## Whitelist System

Scripts that support whitelisting allow you to mark specific players as friends, enemies, or neutral. Whitelisted friends are skipped by all targeting systems and colored separately in visuals. Each script documents its own whitelist behavior.

---

## Silent Aim

Silent Aim is included in scripts where applicable. It may not work depending on your executor and the game.

- Requires hookmetamethod support
- Server-side ray validation will block it on some games
- If it does not work, disable it — everything else runs independently

---

## Requirements

- A Roblox executor with loadstring enabled
- hookmetamethod support for Silent Aim (optional, executor dependent)

---

## Modifying Scripts

These scripts are open source and intended to be modified. The codebase is structured so individual systems are easy to find and change — targeting, visuals, movement, and lock behavior are all separated.

We do not condone using these scripts to ruin other players' experiences. Modifying, learning from, and building on the code is the point.
